# منصة التطوير والتدريب — جمعية تحفيظ بريدة

نظام لإدارة دورة التدريب كاملة: تحليل الاحتياج، الخطة، التنفيذ (حضوري، مكتبة إلكترونية، مواد مقروءة، دورات خارجية، زيارات ميدانية)، وقياس الأثر بمستويات كيركباتريك الأربعة.

## البنية

| الجزء | المكان |
|---|---|
| الواجهة | `public/index.html` (تُولَّد من `scripts/original.html` عبر `scripts/patch.py`) |
| الخادم | `src/worker.js` على Cloudflare Workers |
| قواعد الصلاحيات | `src/rules.js` — تُفحص في الخادم مع كل حفظ |
| قاعدة البيانات | Cloudflare D1 — البنية في `migrations/0001_init.sql` |
| البيانات الأولية | `migrations/0002_seed.sql` (تجريبية، تُولَّد بـ `npm run seed`) |

## الأمان

- دخول بالبريد وكلمة مرور (PBKDF2)، وقفل مؤقت بعد 5 محاولات فاشلة، وجلسات بملف تعريف آمن (HttpOnly, Secure, SameSite=Strict).
- يصدر مسؤول النظام كلمة مرور مؤقتة لكل مستخدم من «المستخدمون والصلاحيات ← كلمة المرور»، ويُجبَر المستخدم على تغييرها عند أول دخول.
- كل سجل يُحفظ منفردًا برقم إصدار؛ إن عدّله شخص آخر قبلك يُكشف التعارض ولا يضيع تعديل أحد.
- الخادم يرفض: تعديل الموظف لدوره أو اعتماده طلبه بنفسه، وتغيير مسؤول النظام لأدوار حسابه، وكتابة أي دور خارج صلاحياته.

## التشغيل محليًا

```bash
npm install
npm run seed            # يولّد البيانات الأولية وcredentials.json (لا يُرفع)
npm run migrate:local
npm run dev             # http://localhost:8787
```

## النشر على Cloudflare

1. أنشئ قاعدة D1 باسم `qb-training-db` وضع معرّفها في `wrangler.toml` مكان `REPLACE_WITH_D1_DATABASE_ID`.
2. اربط المستودع من لوحة Cloudflare (Workers ← Import a repository)، وأمر النشر: `npm run deploy` (يطبّق ترحيلات قاعدة البيانات ثم ينشر).
